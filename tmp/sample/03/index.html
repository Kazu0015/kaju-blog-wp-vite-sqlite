9つの機能・特徴

POINT 01

本編の執筆

本編の執筆ができます。フルスクリーンモードで執筆に集中することが出来ます。

POINT 02

物語の設定

テーマ/世界観/時代設定/物語のゴール/など、自由に物語の設定を登録できます。

POINT 03

プロット作成

起承転結/三幕構成/序破急/など、自由に項目を設定してプロットを作ることが出来ます。

POINT 04

人物設定

登場人物のキャラクター設定を自由に登録できます。

POINT 05

時系列整理

物語の時系列を自由に登録できます。

POINT 06

用語集設定

小説に使用する用語とその定義を自由に登録できます。

POINT 07

バージョン管理

過去の執筆状態を確認することや戻すことが可能です。

POINT 08

バックアップ

執筆した文章はもちろん、物語の設定やプロットもテキストデータでバックアップを取ることが可能です。

POINT 09

不必要な機能は非表示

機能のオンオフは自由に設定できます。不必要で邪魔な機能がメニューに表示されることはありません。

よくあるご質問

支払い手段を教えてください。

支払いはクレジットカード払いのみになります。対応カードは下記になります。VISA / Master Card / JCB / American Express / Discover / Diners

有料プランから無料プランに変更したらデータは消えてしまいますか？

無料プランは作成できる小説の数は1つとなります。有料プランで2つ以上作成している場合は、プラン変更時に残す小説を1つ選択することになります。それ以外は消えてしまうので、変更前にバックアップでデータをご自身のPCに保存しておくことをおすすめします。

操作は難しくないですか？

直感的に操作できるようになっています。使い方ガイドもあるので、安心して使っていただけると思います。

領収書は発行できますか？

管理画面からpdfで発行が可能です。
